> **本地 MVP**：`/insight` · `GET /api/insight/*`（2026-06-05）

### 数据内容

- 第一阶段品牌约束过滤后的**可见品类池**
- 市场趋势时序：搜索量、销量、增速、社媒热度、飙升词
- 竞争格局：市场大盘、SKU 密度、CR3/CR5、头部销量占比、同质化评分
- 供需缺口：价格带、搜索量、供给数、供需比
- 洞察卡片：规模、增速、竞争格局、难度、价格空白、启动资金、推荐结论

### 分析维度（三图三问）

| 维度 | 核心问题 | 图表 | Tab 结论 |
|------|----------|------|----------|
| 机会在哪里 | 哪些赛道在加速 | 趋势折线图 | 趋势判断 + TOP3 推荐明细 |
| 竞争难不难 | 头部是否垄断 | 竞争散点图（大盘 × 集中度） | 竞争结论 + TOP3 |
| 供需缺口在哪 | 哪个价格带供给不足 | 价格带柱状图（PRD 单柱 + 供给深浅） | 供需结论 + TOP3 |

### TOP3 推荐明细字段（每个 Tab）

- 类目名称
- 月搜索量
- 12 月增速
- 社媒热度
- 飙升词
- 各平台增速（天猫/抖音/小红书等）
- TAM/SAM/SOM 简述（潜力清单联动）

### 洞察卡片（表格）

| 列 | 说明 |
|----|------|
| 品类 | 类目名称 |
| 市场规模 | 年化规模区间 |
| 市场增速 | 近 12 月增速 |
| 竞争格局 | 分散/集中等模式描述 |
| 竞争难度 | 低/中/高 |
| 价格空白 | 供需缺口价格带 |
| 启动资金 | 预估冷启动成本带 |
| 决策标签 | 推荐立项 / 建议观望 / 建议放弃 |
| 匹配标签 | 预算匹配、目标品类等 |

**排序规则**：已有目标品类置顶；再按品牌约束（预算、利润、供应链）与机会分综合排序。

### 其他产出

| 产出物 | 说明 |
|--------|------|
| 潜力类目清单 | 含 TAM/SAM/SOM 与进入建议 |
| 痛点优先级清单 | 差评高频词 + 出现频次 + 情绪极性 + 排序 |
| 人群初步画像 | 核心人群、场景、消费动机摘要 |
| 趋势总判断 | 管理摘要区一句话结论 |

### 页面原型要点

1. **平台视角切换**：全平台 / 天猫 / 抖音 / 小红书 — 图表与 TOP3 随平台重算  
2. **关注列表**：用户可将类目加入 watchlist，便于后续机会页跟踪  
3. **进入最佳机会**：从摘要区一键跳转 `/opportunity/:cardId`  
4. **与信号雷达联动**：强信号对应 cardId 可深链至机会页  

### 数据依赖（生产级）

- 12～24 个月搜索指数 + 社媒声量交叉验证  
- 各平台类目 CR3/CR5 与 SKU 密度  
- 价格带供需分布  

**本地 MVP**：H2 内置样例 + 规则引擎个性化；对外称「内置样例 + 规则个性化」。
