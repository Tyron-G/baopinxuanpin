# 开发稳定性修复说明

> 日期：2026-06-05  
> 范围：后端团队协作仓储、开发启动脚本、前端构建缓存管理、日志降噪、前端构建优化

## 修复内容

### 1. 修复产品指标接口异常

运行日志中发现 `GET /api/dashboard/product-metrics` 触发后端 500：

```text
InvalidDataAccessApiUsageException: The getKey method should only be used when a single key is returned.
```

原因是 H2 在 `team_member` / `team_assignment` 写入后返回了 `id` 与 `created_at` 多个 generated keys，而 `GeneratedKeyHolder.getKey()` 只能处理单 key。

本次将团队协作仓储的新增成员、新增任务写入改为只请求 `id` 生成列，并增加兼容取值逻辑，避免 H2 或后续数据库驱动返回多 key 时再次异常。

影响文件：

- `backend/src/main/java/com/oneaix/selection/repository/JdbcTeamRepository.java`
- `backend/src/test/java/com/oneaix/selection/repository/JdbcTeamRepositoryTest.java`

### 2. 增加本地开发启动脚本

新增 `scripts/start-dev.ps1`，启动顺序为：

1. 停止本机 `8088` / `5173` 旧监听进程
2. 启动后端
3. 轮询 `http://127.0.0.1:8088/actuator/health`
4. 后端健康后再启动前端

这样可以减少 Vite 先启动导致的首屏 `/api/*` 代理 `ECONNREFUSED`。

使用方式：

```powershell
pwsh ./scripts/start-dev.ps1
```

### 3. 清理前端构建缓存污染

`frontend/tsconfig.tsbuildinfo` 是 TypeScript 增量构建缓存，不应进入版本库。本次将其从 Git 索引移除，并加入 `.gitignore`。

### 4. 降低后端误访问日志噪音

直接访问后端根路径 `/` 时改为跳转到 Swagger；缺失静态资源（如 `/favicon.ico`）按 404 返回，不再作为 500 未处理异常打印长堆栈。

影响文件：

- `backend/src/main/java/com/oneaix/selection/controller/HomeController.java`
- `backend/src/main/java/com/oneaix/selection/exception/GlobalExceptionHandler.java`

### 5. 加固团队协作种子数据幂等性

`team_member` 增加 `(brand_id, account_id)` 唯一约束，重复插入同一账号时返回已存在成员，避免并发或重复调用导致团队成员重复。

影响文件：

- `backend/src/main/resources/schema.sql`
- `backend/src/main/java/com/oneaix/selection/repository/JdbcTeamRepository.java`

### 6. 优化前端构建与图表类型

Vite 分包将 ECharts、ZRender、Vue、Vue Router 与 Element Plus 相关依赖拆分到更稳定的 vendor chunk，减少默认入口 chunk 体积；机会散点、舆情象限、竞争散点图的 ECharts formatter 从 `any` 改为明确 tuple 类型，降低字段下标误用风险。

影响文件：

- `frontend/vite.config.ts`
- `frontend/src/components/opportunity/OpportunityScatter.vue`
- `frontend/src/components/opportunity/SentimentCloud.vue`
- `frontend/src/components/insight/CompetitionMap.vue`

## 验证建议

```powershell
cd backend
mvn test
```

```powershell
cd frontend
npm run build
```

启动后重点验证：

- `GET /api/dashboard/product-metrics?brandId=1`
- `GET /api/dashboard/core-promise?brandId=1`
- 前端 `http://127.0.0.1:5173/` 首屏是否仍出现代理错误
