## 1. 统一用词表

| 避免（旧口径） | 统一使用 | 说明 |
|----------------|----------|------|
| Demo / demo | **应用** / **本地版** / **MVP** | 指可运行产品，不说「演示项目」 |
| mock 数据 / Mock 品类 | **内置样例数据** / **内置类目样例** | H2 `data.sql` 初始化内容 |
| demo 包、`DemoCategory*` | **`content` 包**、`CategoryPlaybook*` | 类目深度内容与信号模板 |
| 种子品牌 / 种子数据 | **类目模板库** / **catalog 模板** | `brand_id=1` 的洞察卡片库 |
| mock 竞品 | **内置竞品样例** | `CompetitorService` 默认店铺 |
| 演示态 / 技术演示 | **约束未完整** / **早期原型界面** | 仅用于描述历史 UI 迭代时可写「早期原型」 |
| selection-demo | **selection-service** | 仅配置与进程名 |

## 2. 技术边界表述（对外一致）

当前为 **本地可运行 MVP**：

- 数据库：H2 内嵌，零配置启动  
- 类目与趋势：内置样例 + 规则引擎个性化  
- 竞品：支持用户添加；另含内置竞品样例  
- **未接入**：真实多平台 API、生产级竞品持久化、消息推送  

表述时用「内置 / 本地版 / 待接入」，避免「假数据」「演示数据」。
