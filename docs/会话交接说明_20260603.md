```powershell

cd backend
mvn spring-boot:run

# 前端（5173）
cd frontend
npm install
npm run dev
```

访问：http://localhost:5173

## 3. 核心 API 清单

| 接口 | 说明 |
|------|------|
| `POST /api/brand` | 创建品牌上下文 |
| `GET /api/dashboard?brandId=` | 侧边栏 KPI |
| `GET /api/radar/signals?brandId=` | 信号雷达 |
| `GET /api/insight/summary?brandId=` | 洞察结论 |
| `GET /api/insight/cards?brandId=` | 排序后洞察卡片 |
| `GET /api/competitor?brandId=` | 竞品列表 |
| `POST /api/competitor?brandId=` | 添加竞品 |
| `GET /api/opportunity/{cardId}?brandId=` | 机会详情 |
| `GET /api/report/{cardId}?brandId=` | 导出报告 |

## 6. 关键设计决策

- 洞察卡片使用 `brand_id=1` 作为 catalog 模板库，新品牌通过规则引擎过滤，无需复制类目样例行
- 产品路径：数据准备 → 信号雷达 → 洞察发现 → 爆品机会 → 竞品监控
- `sessionStorage` 键：`selection-brand-id`
