## 五、按钮动作覆盖

主流程录屏覆盖以下按钮动作：

- 数据准备：下一步、上一步、查看洞察
- 信号雷达：推送今日摘要、填入演示 Webhook、保存配置、回到洞察
- 洞察发现：进入最佳机会、查看全部类目
- 机会榜单：刷新榜单、进入机会
- 爆品机会：查看报告、查看竞品页、返回洞察
- 选品报告：下载 Excel、下载 PDF、下载 Markdown、返回机会
- 竞品监控：自动发现竞品、添加竞品、取消、重置筛选、返回洞察
- 移动看板：信号、榜单、洞察、竞品
- 品牌模型：重新训练
- 试运行优化：刷新诊断、回到机会页
- 开放 API：保存到会话、试调用、清空
- 供需匹配：刷新匹配
- 团队协作：添加成员、取消、新建分派、取消

## 六、重新生成方式

如需重新采集截图与录屏，在项目根目录确认前后端服务已启动后执行：

```powershell
cd frontend
node ./scripts/capture-delivery-assets.mjs
```

脚本会重新生成本目录中的 `页面截图_*`、`页面长图_*` 与 `演示录屏_主流程.webm`。
