## 三、启动方式

### 一键启动

在项目根目录执行：

```powershell
pwsh ./scripts/start-dev.ps1
```

### 手动启动后端

```powershell
cd backend
mvn spring-boot:run
```

### 手动启动前端

```powershell
cd frontend
npm install
npm run dev
```
