# 爆品选品雷达 交付说明

> 术语口径：[`术语与口径说明_20260604.md`](术语与口径说明_20260604.md) · PRD 对齐：[`PRD与实现对齐说明_20260604.md`](PRD与实现对齐说明_20260604.md)

## 交付范围

本次根据 `02 产品PRD/` 与 Claude Code 计划实现一个可运行的全栈应用（本地 MVP）：

- 数据准备：品牌初始化步骤表单，提交后生成品牌上下文。
- 洞察发现：市场趋势折线图、竞争散点图、价格带供需柱状图、洞察卡片。
- 爆品机会：机会散点图、舆情词云、人群场景、机会点评分与决策结论。

## 技术栈

- 前端：Vue 3、Vite、TypeScript、Element Plus、ECharts。
- 后端：Spring Boot 3、MyBatis-Plus、H2 内嵌数据库。
- 数据：`backend/src/main/resources/schema.sql` 建表，`data.sql` 初始化内置样例数据。

## 运行方式

### 后端

```powershell
cd backend
mvn spring-boot:run
```

后端默认端口：`http://localhost:8088`

API 文档（Swagger UI）：`http://localhost:8088/swagger-ui.html`

H2 控制台：`http://localhost:8088/h2-console`

### 前端

```powershell
cd frontend
npm install
npm run dev
```

前端默认端口：`http://localhost:5173`

- `POST /api/brand`

## 内置类目样例

- 宠物智能用品：高增长蓝海，推荐立项。
- 便携式咖啡器具：中等竞争，建议观望。
- 家用清洁机器人：头部集中红海，建议放弃。

## 验证流程

1. 启动后端。
2. 启动前端。
3. 访问 `http://localhost:5173`。
4. 在数据准备页提交品牌信息。
5. 查看洞察页三个图表和洞察卡片。
6. 点击洞察卡片进入爆品机会页，查看机会点评分和决策依据。
7. 观察每页顶部 `WorkflowSummary` 与全局 `WorkflowStepper`，确认主链路状态、当前产物与下一步提示一致。
8. 从爆品机会页进入独立“选品报告”页，验证报告预览、下载 Markdown 与返回机会链路可正常使用。
