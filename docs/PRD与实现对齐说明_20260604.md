## 4. 开放 API

- 基础路径：`/api/open/v1`
- 鉴权：请求头 `X-Api-Key: selection-open-demo`（可在 `application.yml` 的 `selection.open-api.key` 修改）
- 接口：`ranking/top50`、`insight/cards`、`insight/summary`、`opportunity/{cardId}`、`report/{cardId}`
- 前端控制台：`/open-api`（试调用 + JSON 预览）
- 示例：`GET /api/open/v1/ranking/top50?brandId=1`
