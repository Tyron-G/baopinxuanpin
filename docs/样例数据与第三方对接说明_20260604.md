# 样例数据与第三方对接说明

> 日期：2026-06-04（北京时间）  
> 用途：演示/汇报用**样例数据**，非生产级真实 API 对接。

## 1. 第三方数据源（样例）

| 提供方 | API | 展示位置 | 说明 |
|--------|-----|----------|------|
| 蝉妈妈 | `GET /api/connectors/overview` | 数据准备页 | 直播/电商 feed 样例 3 条 |
| 飞瓜数据 | 同上 | 数据准备页 | 短视频 feed 样例 3 条 |
| 1688 | 机会页 `alibaba1688Intel` | `/opportunity/:id` | 报价 SKU 表 + 工厂信用等级 |
| 合享专利检索 | 机会页 `patentIntel` | 同上 | 检索式 + 专利条目表 |

连接状态字段：`status=已同步`、`demoData=true`。

## 2. Webhook 外发（样例模拟）

- 配置项：`selection.push.simulate-delivery: true`（`application.yml`）
- 当 Webhook URL 包含 `demo`、`example.com`、`localhost`、`mock` 时：**不真实 HTTP 外发**，写入 `push_delivery_log` 并返回成功。
- 种子数据：品牌 `brand_id=1` 预置钉钉/企微/微信群演示 URL。
- API：
  - `POST /api/push/digest` — 推送摘要，响应含 `deliveries`
  - `GET /api/push/deliveries?brandId=1&limit=10` — 投递记录

雷达页提供「填入演示 Webhook」按钮。

## 3. 运营 KPI（背景文档样例）

- API：`GET /api/dashboard/product-metrics`
- 展示：洞察页完整看板、侧栏 NPS/留存/ARR、移动端 H5
- 指标覆盖：种子用户 4 周、2 周增速 30%、MVP/迭代1 NPS、MAU、留存、企业版、续费、API 品牌、ARR/MRR 等
- 所有条目 `demoData: true`，**不代表真实经营结果**。
