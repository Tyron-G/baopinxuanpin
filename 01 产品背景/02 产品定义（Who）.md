### 一、产品定义
产品名称：爆品机会雷达

产品类型：SaaS

产品定义：一款实时监控多平台（天猫/抖音/小红书/跨境等）商品数据，自动识别潜在爆品信号，并直接输出“选哪个、为什么选”决策建议的情报工具，帮助品牌方在已有商品池中，快速识别“可切入、可复制、可放大”的爆品机会的情报系统

核心承诺：比市场早X天发现爆品苗头，让选品成功率翻倍

产品边界：**做**：爆品信号监控、机会榜单、竞品追踪、选品建议输出  ；**不做**：不保证100%爆（但给出概率和置信度）、不做供应链对接、不代运营

覆盖范围：已有商品池 → 数据解析 → 机会识别 → 切入判断 → 决策建议

### 二、产品价值
#### 价值主张
让品牌在“已经存在的市场里”，更早、更准地抓住爆品机会

#### 核心价值
提前发现“即将爆”的商品（Early Signal）
判断“能不能做”（Decision）
识别“如何切入”（Strategy）

#### 价值支撑

| 价值点     | 量化承诺                     | 对标痛点  |
| ------- | ------------------------ | ----- |
| 提前发现    | 比主流数据工具早X天捕捉爆品苗头         | 信息滞后  |
| 提高胜率    | 平台推荐品的实际爆品率达到X%          | 拍脑袋决策 |
| 节省时间    | 从“每天2小时手工报表”到“5分钟拿到选品建议” | 数据分散  |
| 避开红海    | 自动标记“竞争红海区”和“蓝海机会区”      | 跟风内卷  |
| 可复用的判断力 | 每次选品自动沉淀归因，形成品牌自己的选品模型   | 缺乏归因  |
#### 客户收益
节省成本
爆品抢占先机
爆品选品知识沉淀
### 三、目标客户与使用场景
#### 目标客户
年GMV1000万~1亿的成长型品牌（有数据意识但无数据团队，被选品困扰，且预算敏感度中）
电商代运营公司（同时服务多个品牌，选品需求量大，且预算敏感度中高）
初创品牌/工厂转型品牌（预算有限但需求强烈，需低门槛入口，预算敏感度高）
#### 用户角色

| 角色        | 职责           | 使用频率   | 关注点             |
| --------- | ------------ | ------ | --------------- |
| **电商运营**  | 日常选品、上架、测款   | 每天     | 今天该选什么、竞品在卖什么   |
| **选品/买手** | 负责品类规划和供应链对接 | 每周2-3次 | 哪些品类有机会、供应链是否可行 |
| **品牌负责人** | 最终决策，看ROI    | 每周1次   | 选品成功率、投入产出比     |
#### 使用场景

|场景|用户角色|触发事件|核心任务|期望输出|
|---|---|---|---|---|
|**月度选品会**|运营/选品经理|每月初需要确定下月新品方向|从候选品类中筛选3-5个潜力方向|品类机会榜单 + 每个品类的核心卖点建议|
|**追爆品**|品牌负责人|发现竞品某款卖爆了|快速判断“我能不能跟、怎么跟”|竞品拆解报告 + 差异化建议 + 供应链可行性|
|**测款优化**|投放/运营|新品上架一周数据出来了|判断“要不要加投、要不要放弃”|测款诊断 + 优化建议（改什么/停什么）|
|**日常监控**|电商运营|每天上班第一件事|快速扫一遍“今天有什么新信号”|信号列表 + 重点关注的3-5个品|
|**季度复盘**|品牌管理层|季度结束，复盘选品成败|沉淀选品经验，优化下一季度策略|选品归因报告 + 下一季度机会清单|

### 四、核心优势
我们有什么？
- 多平台实时数据（抖音 / Amazon 等）
- 多品类历史爆品数据库
- 爆品预测模型（增长/生命周期）
为什么选我们？
- 更早：在爆之前发现机会
- 更准：判断生命周期，而不是只看榜单
- 更稳：有ROI和评分支撑决策

|优势维度|具体说明|为什么别人做不到|
|---|---|---|
|**速度优势**|比市场早X天发现爆品信号|自研算法+多源数据融合，捕捉早期苗头|
|**答案直接**|不给你看数据，直接告诉你“选这个”|内置选品模型，把专家经验产品化|
|**多平台融合**|同时监控天猫/抖音/小红书/跨境|打通数据孤岛，交叉验证|
|**价格门槛低**|几千元/月起|标准化SaaS，无需定制实施|
|**无需数据团队**|运营直接用，不需要写SQL|产品化程度高，UI/UX优先|
|**归因能力**|告诉你为什么爆/为什么死|沉淀选品方法论，形成品牌自己的模型|

#### 详细里程碑

##### MVP阶段（第1-3个月）

**目标**：用最小成本验证核心假设——“我们能比市场更早发现爆品信号”

| 功能模块       | 具体功能                                | 优先级 |
| ---------- | ----------------------------------- | --- |
| **爆品信号雷达** | 扫描3个核心品类（如美妆/服饰/家居），识别销量增速、社交声量异常的品 | P0  |
| **机会榜单**   | 按机会分数排序，展示TOP50潜力品，每个品标注“为什么推荐”     | P0  |
| **竞品监控**   | 用户手动输入竞品店铺名，系统追踪其新品上架和爆品动向          | P0  |
| **信号推送**   | 钉钉/微信群机器人推送“今日新发现”                  | P1  |
| **基础看板**   | 展示品类趋势、信号数量、关注列表                    | P1  |

**成功标准**：

- 5-10个种子用户连续使用4周
    
- 推荐的品中，至少30%在2周内销量增长超过50%
    
- 种子用户NPS > 30
    

##### 迭代1阶段（第4-6个月）

**目标**：提升准确率、扩展品类、增加自动化能力

**功能清单**：

|功能模块|具体功能|优先级|
|---|---|---|
|**品类扩展**|从3个扩展到10个品类（覆盖主要消费品类）|P0|
|**自动竞品发现**|系统自动识别对标竞品，无需手动输入|P0|
|**卖点建议**|对每个推荐品，输出“建议卖点”“建议价格带”“差异化方向”|P0|
|**报告导出**|支持导出Excel/PDF格式的选品建议报告|P0|
|**信号分级**|将信号分为“强信号/中信号/弱信号”，减少噪音|P1|
|**移动端看板**|手机 H5 移动看板（`/mobile`）；微信正式小程序为后续专项|P1|

**成功标准**：

- 月活跃用户 > 50个品牌
    
- 客户留存率 > 70%
    
- NPS > 40
    
- 推荐准确率（机会分数>80分的品，2周内销量增长>30%的比例）> 50%
    

---

##### 迭代2阶段（第7-12个月）

**目标**：建立壁垒、开放能力、服务大客户

**功能清单**：

|功能模块|具体功能|优先级|
|---|---|---|
|**选品归因模型**|分析历史选品成败，输出“为什么爆/为什么死”的归因报告|P0|
|**品牌专属模型**|根据品牌历史数据，训练专属选品模型（推荐更精准）|P0|
|**API开放**|开放数据接口，供大客户/代运营公司二次开发|P0|
|**跨境平台扩展**|接入亚马逊/Shopee/TikTok Shop等跨境平台|P1|
|**供应链匹配**|推荐已选品的供应链渠道（可选，谨慎扩展）|P2|
|**团队协作功能**|多人账号、权限管理、选品审批流程|P2|

**成功标准**：

- 企业版客户签约 > 10家
    
- 客户续费率 > 80%
    
- 品牌专属模型使用后，推荐准确率再提升20%
    
- API调用品牌 > 20个
